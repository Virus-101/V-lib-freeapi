Free LLM APIs.
One import.

fllm gives you one interface to every free LLM backend: no-key hosted models, free-tier vendors you sign up to yourself, and models on your own machine. Your keys and usage stay on your computer.

What it is

Free tiers are scattered: each vendor has its own endpoint, key, quota and quirks. fllm puts them behind one call. You bring your own free accounts, so every developer works from their own quota instead of a shared one.

Nothing is hosted for you and nothing is sent to us. There is no server in the middle. The library calls the vendors directly from your machine.

1. Install

pip install freeaipi        # gives you both `import freeaipi` and the short `import fllm`
npm install freeaipi        # Node 18+, zero dependencies

Python 3.10+. The only dependency is httpx.

2. Set up your own keys

Two backends need no key at all: Pollinations (rate-limited per IP) and any local model server. For more models and quota, create free accounts and store the keys locally:

fllm init

The wizard walks through each vendor, shows where to get a free key, and saves what you enter to ~/.freeaipi/keys.env (hidden input, owner-only permissions where the OS supports it). Press Enter to skip any vendor.

  1. Sign up for the free tier of the vendors you want (links are shown by fllm init).
  2. Paste each key into the wizard, or later with fllm key set groq.
  3. Check with fllm key list. It shows which keys are set, never the values.
A key already set in your environment always wins over the stored file, so CI and one-off runs behave as you expect. Set FREEAIPI_HOME to keep the state somewhere else.

3. Use it

import fllm

print(fllm.chat("Reply with exactly: OK").content)

fllm.list_models()                       # every free model you can reach
fllm.best(requires_tools=True)           # pick one by capability
for c in fllm.stream("Tell me a story"):
    print(c.delta, end="")

fllm and freeaipi are the same library. Use whichever you prefer.

Tool calling

def get_time(): return "12:00"
tools = [{"type": "function", "function": {
    "name": "get_time", "description": "Current time",
    "parameters": {"type": "object", "properties": {}}}}]
r = fllm.run_tools([{"role": "user", "content": "What time is it?"}],
                   tools, {"get_time": get_time})
print(r.content)

Fallback models

# keys are "<vendor>/<model>"; run fllm list to see yours
fllm.chat("hi", model="pollinations/openai-fast",
          fallback=["groq/<a-model-from-fllm-list>"])

Fallback covers errors and outages. It does not trigger on a rate limit, because a quota is a signal to slow down, not to burn through a different vendor without telling you.

Track your own usage

fllm usage              # calls and tokens per model, from your local ledger
fllm usage --days 7

Every call appends a line to ~/.freeaipi/usage.jsonl with the token counts the vendor reported. It is your own record on your own disk.

Local OpenAI-compatible gateway

Run one command and any tool that speaks the OpenAI API (the openai SDK, LangChain, editor plugins) can use your free models:

fllm serve                      # http://127.0.0.1:8787/v1
from openai import OpenAI
client = OpenAI(base_url="http://127.0.0.1:8787/v1", api_key="unused")
client.chat.completions.create(model="auto",
    messages=[{"role": "user", "content": "hello"}])

model="auto" lets fllm pick. It listens on loopback only and uses your keys, so nothing is exposed.

Honest limits

  • Free means a free tier, not unlimited. Quotas, model lists and terms are the vendors' and change without notice. Catalogues are fetched at run time.
  • Some vendors in the preset list have not been exercised against live endpoints yet. The code marks which have (verified).
  • Paid APIs are out of scope. Presets that are not free are flagged as such.
  • Usage figures come from what each vendor reports. Treat them as your own estimate, not an invoice.
  • Local models are not downloaded for you, and their capabilities are inferred from names.
  • Respect each vendor's terms: use your own account and key. Do not pool keys across people.
